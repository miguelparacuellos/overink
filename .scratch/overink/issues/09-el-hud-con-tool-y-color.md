# 09: El HUD con Tool y color activos

**What to build:** Un indicador fijo en una esquina que diga qué herramienta y qué color están
seleccionados, para no descubrir el error al empezar el trazo. Lo ve también el alumno, porque
forma parte de la pantalla compartida, así que debe ser discreto.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Mientras el Overlay está en Armed, el HUD es visible en una esquina
- [ ] Muestra la Tool activa y el color activo
- [ ] Se actualiza en el momento en que se pulsa el atajo correspondiente
- [ ] En Dismissed no se ve nada
- [ ] No es interactivo: solo informa, no se clica
- [ ] Es lo bastante discreto para convivir con una clase compartida a pantalla completa
