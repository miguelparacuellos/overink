# 05: Borrar Marks con el Eraser

**What to build:** Poder quitar algo de la pizarra pasando el lápiz por encima, sin tener que
repasarlo entero: rozar un trazo lo elimina completo. Y si uno se pasa borrando, se deshace.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] El Eraser elimina por completo cada Mark que toca
- [ ] No borra fragmentos ni deja trozos de un Mark: o está entero o no está
- [ ] El Eraser no produce ningún Mark propio
- [ ] Cada borrado es una operación del History y se deshace con Cmd+Z
- [ ] Rozar varios Marks en un mismo gesto los elimina todos
- [ ] Hay tests de borrado, de que no quedan fragmentos y de deshacer un borrado
